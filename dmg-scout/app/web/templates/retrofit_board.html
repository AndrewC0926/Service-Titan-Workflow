Replacement candidates — no permit on record, absence is the signal

Commercial/industrial buildings old enough to need replacement with ZERO mechanical permit on file across this system's full permit window, above the sqft floor. A permit means someone already replaced the equipment; its absence means either the original equipment is still running or it was swapped without a permit — either way, a live candidate. No equipment TYPE, no permit-verified tonnage: neither can be known without a permit's work description. Service life IS shown, computed from YearBuilt as an install-year proxy (marked YearBuilt-derived, never presented as the permit-verified figure recently-active rows carry); tonnage is a wide sqft-derived estimate, not a mined figure. CARB/EBEWE candidacy comes from assessor use code alone and applies here the same as the recently-active population; SB 1206 never fires here structurally (it needs an install year inside R-410A's post-2010 window, and this whole population is built before 2010).

Absence is an inference, not proof — read this before calling anyone The expected error here skews toward FALSE POSITIVES, not false negatives: a like-for-like equipment swap doesn't always require a permit, so a real replacement can still show up on this list as "no permit on record." The permit↔parcel address/APN join is also imperfect — a permit filed under a slightly different or mismatched APN can make an already- serviced building look untouched. Treat this list as an upper-bound opportunity population to qualify by phone, not a confirmed one. Service-life status on these rows is a YearBuilt proxy, not a permit-verified install date — actual equipment could be older (original, never replaced) or younger (replaced without a permit) than shown.
