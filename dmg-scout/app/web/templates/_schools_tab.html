How this is built
Never auto-linked to a project Every row here is OPSC's own School Facility Program funding record — never auto-linked to an existing project and never used to create a new one. A fuzzy (District, School Name) match against an existing Legistar or CEQAnet project goes to the review queue as a candidate, same as any other uncertain match; with no match at all, the row simply stands alone here. Call target: districts on call_target.standards_owners are Owner (standards program) regardless of status; otherwise Status "Funds Released" is Bidding contractors (the spec is locked), any earlier status is Engineer (the mechanical basis of design is still being decided).
