How this is built
HCAI's own public seismic ratings, verbatim — deadlines are Scout's own derived reading Sourced from HCAI's public CHHS Open Data CSV "Seismic Ratings and Collapse Probabilities of California Hospitals" — one row per seismically-separate building, SPC and NPC ratings exactly as HCAI publishes them. spc_deadline_year/npc_deadline_year below are NOT an HCAI-published field: they're this application's own reading of the base SB 1953 statutory schedule (SPC-1 → {{ spc1_year }}, SPC-2 → {{ spc2_year }}; the {{ npc5_year }} standard also requires NPC 5) — see /assumptions for the exact HCAI-quoted language. The "extension filed" flag is a coarse yes/no — a building so flagged may have a LATER real deadline than shown; read HCAI's own extension record before treating either date as final, never this system's guess at which of six extension bills governs. Imported by hand, not a live feed — CHHS's own Terms of Use don't clearly sanction automated access; see /assumptions for the full finding. Not merged with the project board or retrofit — a different sale, a different buyer.
