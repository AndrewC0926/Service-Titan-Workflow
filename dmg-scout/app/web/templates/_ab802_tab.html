How this is built
Rank inputs shown, not a black-box score Sorted by (age percentile + EUI percentile), each computed WITHIN the building's own property type — a 1980 office and a 1980 warehouse don't share a normal EUI range, so ranking them against each other would mean nothing. Both percentiles are their own columns below, not folded into one number: "Older %" is how much of its own property type this building is older than; "EUI %" is how much of its own property type it uses more energy than, weather-normalized. A building missing Year Built or EUI simply has no percentile for that half — never guessed at, never defaulted to a mid-point.
How this is built
Assessor match is a building match, not an owner match "Assessor match" links a row to a matched RetrofitBuilding record — lat/long within 30m first, normalized address second (see /assumptions for the measured rate and method breakdown) — never an owner. No free, bulk-queryable LA County assessor owner-name source exists at all (see RetrofitBuilding's own docstring); this board shows "no owner data available" for exactly that reason, on every row, permanently. Where a row also matches an LA EBEWE benchmark filing by address, that filing's own self-reported organization field is shown labeled "benchmarking filer" — the entity that filed the EBEWE benchmark, not a verified owner. Both joins, and this whole population, are LA County only — the only county this app's assessor/EBEWE data covers; outside LA, a row stands alone with its Property Name.
