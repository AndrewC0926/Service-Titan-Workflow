Replacement leads — owner-direct lane
No engineer in this path: a service contractor already holds the owner relationship. The play is handing them a list of aging buildings near their own yard, not calling owners cold — so this is organized by contractor, not by building.
How this is built
Ranked by urgency, not by how many buildings are nearby Sort key is nearby_urgency_score — the SAME cross-contractor ranking field /contractors already uses (sum of each nearby building's service-life years-past-due, capped 100yr each), at contractors.ranking_radius_miles ({{ radius_miles }}mi) — not the wider {{ '%.0f'|format(15) }}mi single-contractor radius the account detail page uses. That wider radius was tried first for this board and rejected: measured against production 2026-08-24, it returned 13,000+ "nearby" overdue buildings for a dense-area contractor (not a list anyone could hand over) and the batched query itself took over 5 minutes against ~5,400 mechanical contractors, vs ~100s at this tighter radius — the same dense-area discrimination problem /assumptions already documents for the general ranking. Precomputed by scout match-contractors and scout match-contractors-overdue — not live, and the two can be refreshed at different times (each row shows its own as-of date).
How this is built
"No permit on record" is an inference, not a fact Every building below is in the replacement_candidate population: no permit was found for it, so the equipment's age is inferred from the assessor's YearBuilt and a service-life band — see the retrofit report for the same discipline in full. Some of these buildings were genuinely replaced without ever pulling a permit; a "no permit on record" building is not proven to still have original equipment, it is simply undocumented — never claimed as verified.
