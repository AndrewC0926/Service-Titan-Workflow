How this is built
Two radii for two questions: ranking vs. counting Sort key is nearby_urgency_score — the SAME cross-contractor ranking field /contractors already uses (sum of each nearby building's service-life years-past-due, capped 100yr each), at contractors.ranking_radius_miles ({{ ranking_radius_miles }}mi) — tight on purpose, because that's what discriminates between contractors in dense areas; see /assumptions. The overdue count each contractor shows, and the buildings on their printable handout, use a DIFFERENT, wider radius instead — contractors.default_radius_miles ({{ count_radius_miles }}mi), "realistically reachable" — because ranking and counting are different questions. An earlier version used the tight radius for both and measured 53% of mechanical contractors at zero; see /assumptions for how much of that was the radius, not a genuine absence of nearby buildings. Precomputed by scout match-contractors and scout match-contractors-overdue — not live, and the two run on the same weekly schedule but can still show different as-of dates if one fails (each row states its own).
How this is built
"No permit on record" is an inference, not a fact Every building below is in the replacement_candidate population: no permit was found for it, so the equipment's age is inferred from the assessor's YearBuilt and a service-life band — see the retrofit report for the same discipline in full. Some of these buildings were genuinely replaced without ever pulling a permit; a "no permit on record" building is not proven to still have original equipment, it is simply undocumented — never claimed as verified.
